# todo-php-project
# Тапсырмалар менеджері (To-Do Manager)

## Жоба туралы
Бұл веб-қосымша пайдаланушыларға күнделікті тапсырмаларды жоспарлауға, санаттарға бөліп, олардың орындалу барысын қадағалауға мүмкіндік береді. Жоба PHP және MySQL қолдану арқылы әзірленеді.

## Негізгі мүмкіндіктер
* Пайдаланушыларды тіркеу және авторизация (Session, Password Hashing).
* Тапсырмаларды қосу, көрсету, өңдеу және жою (CRUD операциялары).
* Санаттар бойынша топтау.
* Тапсырмаларды іздеу және сүзу.
* Қауіпсіздік шаралары (PDO Prepared Statements, htmlspecialchars).

## Технологиялық стек
* **Frontend:** HTML5, CSS3, JavaScript
* **Backend:** PHP (PDO)
* **Дерекқор:** MySQL

## Дерекқор құрылымы (ER-диаграмма)
Жоба келесі 3 негізгі кестеден тұрады:
1. **users** — Пайдаланушылар мәліметі (id, username, email, password, created_at).
2. **categories** — Тапсырма санаттары (id, user_id, name).
3. **tasks** — Тапсырмалар тізімі (id, user_id, category_id, title, description, due_date, status, created_at).
